# ClickableRaidBuffs v7.1.20 Release Notes

- Added a new Raid Buff ownership mode option in Customize: `All Raid Buffs` or `Mine Only`.
- In `All Raid Buffs` mode, raid buff icons now only appear when at least one current group member can provide that buff.
- Fixed raid buff coverage totals to prevent overcounting and keep display totals consistent with actual group size.
